# Universal City Data Format

`DataPacks/universal/` publishes every Just-Go-supported city as one self-contained JSON
document in a single, versioned schema, so developers can consume the project's transit
data without reverse-engineering the app's internal formats. The files are generated by
`Scripts/generate_universal_city_data.rb` from the committed artifacts (manifest, metro
networks, bundled city packs, official-resource catalog, rights inventory), validated in
CI by `Scripts/validate_universal_city_data.rb`, and regenerated deterministically — the
same sources always produce byte-identical output.

## Files

- `universal/index.json` — the directory: one entry per city with `path`, `sizeBytes`,
  `sha256` (integrity of the exact file bytes), `hasNetwork`, `lineCount`, `stationCount`.
- `universal/<cityID>.json` — one minified document per city (58 cities).

## Versioning

- `formatVersion` (integer, currently `1`) changes only when the document shape changes
  incompatibly. Additive fields do not bump it.
- `generatedAt` is derived from the newest committed source stamp, not the build clock.

## Document shape (`formatVersion` 1)

| Field | Contents |
| --- | --- |
| `city` | `cityID` (GB 2260-style admin code, e.g. `1100` Beijing, `8100` Hong Kong), `name` (Simplified or local Chinese), `nameEn`, `nameTraditional`. |
| `capabilities` | Per-domain sourcing status (`accessibility`, `schedules`, `liveArrivals`, `stationMaps`, `licensedMedia`, `verifiedTransferContexts`) with values like `official_static`, `external_only`, `metadata_only`, `source_pending`. |
| `coverage` | `networkStations` plus `{covered, total}` for each capability metric. |
| `network` | The metro network graph, or `null` for the 12 catalog-only cities. Contains `version`, `geometrySource`, `geometryKind`, `coordinateSystem` (**`gcj02` for mainland China, `wgs84` elsewhere — do not mix them up when plotting**), `attribution`, `licenseURL`, `sourceSnapshot`, `bounds`, `lines[]`, `stations[]`. |
| `network.lines[]` | `id`, `logicalLineID`, `routeReference`, `name`, `nameEn`, `colorHex`, ordered `stationIDs[]`, `servicePatterns[][]`. Line geometry `paths` are deliberately omitted to keep files small; the ordered station sequences preserve topology. Fetch full geometry from the `Just-Go/Resources/MetroNetworks/<cityID>.json` source file if you need it. |
| `network.stations[]` | `id` (16-hex content-derived identifier — regenerated when upstream data is rebuilt, so treat as opaque and non-permanent), `name`, `nameEn`, `latitude`, `longitude`, `lineIDs[]`. |
| `stationDetails[]` | Reviewed per-station records from the bundled city pack (`stationID` matches `network.stations[].id`): `stationName`, `stationNameEn`, `aliases`, `accessibility` (elevators, ramps, tactile paths, accessible entrances, facility notes — Hong Kong today), `schedules`, `stationFacilities`, `externalResources`, `licensedMedia`, `liveArrivalReferences`. Empty for cities without a bundled pack. |
| `destinationNames` | Realtime destination-code dictionary (Hong Kong), else `null`. |
| `officialResources` | The reviewed official-link catalog for the city: `reviewStatus`, `verifiedAt`, `officialDomains[]`, `cityResources[]` and per-station `stationResources[]` (kind/title/targetURL/provider/scope/format), `coverage`. Links are factual metadata pointing at operator-hosted pages; no operator content is embedded. |
| `rights` | `rightsIDs[]` plus the resolved `declarations[]` from `DataPacks/rights_inventory.json` (license SPDX, source URL, attribution, redistribution terms). |

## License and attribution obligations for consumers

The universal files aggregate sources under different terms — the per-city `rights`
block is authoritative for that city:

- **Network data** derives from OpenStreetMap (`© OpenStreetMap contributors`, ODbL);
  redistribution or derived databases must comply with the
  [ODbL](https://www.openstreetmap.org/copyright), including attribution and share-alike.
- **Hong Kong accessibility/schedule content** derives from DATA.GOV.HK datasets (MTR
  Corporation Limited); follow the DATA.GOV.HK terms of use referenced in the rights
  declarations.
- **Official resource links** are factual URL metadata; the linked content itself remains
  the operator's, under the operator's own terms. Linking implies no endorsement.
- **Catalog structure and generated metadata** are MIT-licensed Just-Go artifacts.

These files are repository artifacts for developers; the iOS app does not bundle
`DataPacks/universal/`.
